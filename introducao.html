    Este documento é um curso introdutório à linguagem [Dart], concebido segundo o mesmo princípio do curso [Introdução à linguagem TypeScript e ao framework web NestJS por meio de exemplos (2026)]: aprender uma linguagem por meio de uma série de pequenos scripts independentes, comentados linha por linha, em vez de uma exposição teórica de sua gramática.

    A progressão segue exatamente a do curso de TypeScript: os mesmos conceitos, na mesma ordem, com um script Dart ao lado de cada script TypeScript. Essa simetria é intencional: ela permite comparar diretamente, a qualquer momento, como Dart e TypeScript atendem à mesma necessidade — e identificar, para cada diferença, o que decorre de uma simples escolha de sintaxe e o que decorre de uma diferença fundamental entre as duas linguagens (tipagem estrutural versus tipagem nominal, compilação versus transpilação, presença ou ausência de coerção implícita etc.).

    Dois capítulos do curso de TypeScript foram intencionalmente omitidos aqui: [Introduction to the NestJS Web Framework] e [Case Study: The Tax Calculation Server in NestJS]. Esses dois capítulos tratam de um framework web do lado do servidor escrito em TypeScript — assunto que não tem relação direta com o aprendizado da linguagem Dart em si. O servidor NestJS de cálculo de imposto, em contrapartida, é mantido: uma vez instalado (veja o capítulo “Instalação de um servidor NestJS”), ele serve como alvo real para testar as funções HTTP de Dart — exatamente como serve de alvo para os clientes HTTP e TypeScript do curso original.

    No entanto, uma diferença de escopo distingue este curso do curso de TypeScript: a seção [The Fundamentals] do curso de TypeScript dedica três seções inteiras às atualizações recentes do ECMAScript (2020–2024, 2026) e à API [Temporal]. Esses recursos novos são específicos de JavaScript/TypeScript e não têm equivalente direto em Dart; aqui eles são substituídos por uma seção sobre as [Dart 3.x New Features], dedicada aos recursos recentes específicos de Dart: [records], [pattern matching], classes [sealed] e modificadores de classe.

    1.1. Público-alvo e pré-requisitos

    Este curso destina-se a leitores que já conhecem programação — idealmente, aqueles que já fizeram o curso de TypeScript, pois a comparação constante entre as duas linguagens é central na abordagem pedagógica adotada aqui. Nenhum conhecimento prévio de Dart é necessário: cada novo conceito é introduzido por meio de um script mínimo, comentado em detalhe.

    Ao contrário da ideia equivocada comum que reduz Dart a “a linguagem do Flutter”, este curso não aborda Flutter nem interfaces mobile em momento algum: Dart é usado aqui como linguagem de programação de uso geral, executada pela linha de comando ([dart run]), exatamente como TypeScript era usado com [tsx] no curso original.

    1.2. Organização do projeto de exemplo

    Os scripts deste curso são fornecidos em uma estrutura de diretórios separada, [dart-fundamentals/], que espelha a estrutura de pastas do curso de TypeScript ([basics/], [arrays/], [objects/], [strings/], [regexp/], [functions/], [exceptions/], [modules/], [async/], [classes/], [http/]...), mais uma nova pasta, [dart3/], para a seção [Dart 3.x New Features]. Uma segunda árvore de diretórios, [dart-databases/], contém o capítulo “Acesso a bancos de dados”. Cada pasta contém seu próprio [README.md] e, quando necessário, seu próprio [pubspec.yaml] (o equivalente Dart do [package.json] do Node.js; veja o capítulo seguinte).

    Cada script é executado individualmente com o comando [dart run], seguido do caminho do script — por exemplo, [dart run dart-fundamentals/basics/basics_01.dart]. Não é necessária uma instalação completa do projeto para executar um único script: basta [dart pub get] (equivalente a [npm install]), executado uma vez na raiz de uma pasta que contenha um [pubspec.yaml], para instalar as dependências de todos os scripts que ela contém.
