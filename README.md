# Introdução à linguagem Dart por meio de exemplos

> ⚠️ **Este repositório não é um projeto de software.** Não há nenhuma aplicação para instalar, nenhum pacote para publicar, nem problemas de código para corrigir: este é um **material de curso**, escrito para estudantes que aprendem a linguagem Dart.

**👉 [https://stahe.github.io/br-dart-sept-2026/](https://stahe.github.io/br-dart-sept-2026/)**

Nenhuma instalação é necessária para lê-lo: basta um navegador.

## 🎯 A quem se destina este curso?

Este curso se destina a estudantes que **não têm nenhum conhecimento prévio** da linguagem Dart.
Ele foi concebido segundo o mesmo princípio do curso *Introdução à linguagem TypeScript e ao
framework NestJS*: aprender uma linguagem por meio de uma série de scripts pequenos e independentes,
comentados linha por linha, em vez de uma explicação teórica de sua gramática. A estrutura do curso segue a do curso passo a passo de TypeScript, com um script Dart ao lado de cada script TypeScript, para permitir uma comparação direta de como as duas linguagens atendem à mesma necessidade.

## 📚 Roteiro do curso

O curso está organizado em grandes seções:

1. **Configuração do ambiente de desenvolvimento** — verificação das ferramentas, configuração do projeto no VS Code, primeiro script, análise estática, linter e a extensão Dart.
2. **Fundamentos do Dart** — noções básicas da linguagem, arrays, objetos,
   strings, expressões regulares, funções, erros e
   exceções, módulos, programação orientada a eventos e funções assíncronas,
   classes e os novos recursos do Dart 3.x (records, patterns, classes seladas).
3. **Instalação de um servidor NestJS** — o servidor de cálculo de imposto de renda,
   tirado diretamente do curso de TypeScript: ele serve como alvo realista para testar as funções HTTP do Dart,
   assim como serve de alvo para os clientes HTTP do curso original. (Os capítulos que ensinam o próprio NestJS foram omitidos de propósito aqui: esse é um
   assunto que não está diretamente relacionado ao aprendizado da linguagem Dart.)
4. **Funções HTTP do Dart e clientes para o serviço de cálculo de imposto** — quatro
   variantes de cliente para o mesmo servidor: um script CLI simples, camadas DAO/lógica de negócio separadas,
   um projeto compilado e, por fim, uma aplicação web completa com uma interface HTML.
5. **Acesso a banco de dados** — o driver MySQL nativo, seguido de um "ORM leve" escrito à mão, já que não existe um equivalente maduro do TypeORM ou do Prisma para Dart.
